## 一、加了两套真招式

之前的美女僵尸**近战只有继承来的原版 `ZombieAttackGoal`，远程一个都没有** —— `BOUQUET` 看着像投掷，实际是 7 格 / ±60° 的**即时扇区结算，没有飞行物**（`BrideZombie.java:676-696`）。本版把这两块补成真技能。

| | `VEIL_SWIPE` 纱袖横扫（近战） | `FLOWER_DART` 抛花刺（远程） |
|---|---|---|
| 起手条件 | 目标距离 **1.0 – 4.5 格** | 目标距离 **4 – 16 格** |
| 时长 / 命中点 | **2.0s / 第 1.0s**（`VEIL_SWIPE(40, 20)`） | **1.8s / 第 0.9s**（`FLOWER_DART(36, 18)`） |
| 结算 | 面前 **±75° / 3 格**扇区：**伤害 8 + 击退 2 + 缓慢 2s** | 甩出**独立投射物**，命中：**中毒 + 缓慢** |
| 打谁 | 扇区内**非怪物**目标 + 她当前的目标 | 命中的实体 |
| 剪辑 | `skill_veil_swipe`（40 根骨） | `skill_flower_dart`（42 根骨） |
| 姿势设计 | 提袖后引 → **水平反手横抡**（主动轴在 z / 体侧外展） | 沉肩侧身 → **低位前送甩掷**（出手点低、轨迹平） |

- 两套与已有的 `BOUQUET`（过肩、垂直面鞭打）**在姿势上刻意区分**：花束是高位的臂鞭，横扫是水平抡扫，抛花刺是低位甩掷。
- 横扫**只打非 `Monster`**：她身边常常挤着自己的召奬（`CharmedZombie`），会打自己人的横扫等于清场自残。另外她的**当前目标**永远吃伤害（哪怕目标是个怪）。
- 击退在服务端改速度后必须 `victim.hurtMarked = true`，否则客户端看不到位移。

## 二、轮转从 8 套扩到 10 套 + 死锁兜底

两位新技能**追加在 `EliteAbility` 枚举末尾**（`byId` 用 ordinal 走网络同步，插中间会让别的精英的施法状态错位到别的技能上），并进 `ROTATION` 轮转、各自带冷却（近战 180 / 远程 220 tick）。

**关键修复：轮转会被距离条件卡死。** 轮转只在「轮到的那一套起手条件成立」时才推进 ⇒ 再塞一个贴脸技能后，玩家一直站远处 = 她**所有技能永久停摆**。本版加了兜底：

- 轮到的这一槽**连续 100 tick（`ROTATION_SKIP_TICKS`）起不了手就跳过**，推进到下一槽；
- **但冷却中的槽不跳** —— 冷却是自己会走完的，跳掉只会让技能顺序变得不可预测。

### 两个坑（都已写成断言）
1. **表里写了幅度、剪辑里没有该轴 ⇒ 静默空转**。本轮真踩到：`skill_bouquet` 的 z、`summon` 的 y 只写在表里，剪出来一点没动 ⇒ 校验器要求**表 ↔ 动画逐轴相等**（只断「不为 0」抓不住这类）。

## 1.1.33 手臂攻击变明显（2026-09-26）

**问题**：三套攻击全靠「侧摆 z」横向抹过去，前举 x 只有 Δ18–20°，而**肩膀的 y/z 通道全程为 0**（13 个剪辑里一个都没写）。实测证据：非攻击的「送花束」前举 Δ76°，**比两套攻击都大**。第三人称侧后视角下，横着抹的手臂就是一条线。

**结论**：不是幅度不够，是**动作平面选错 + 肩膀没参与**。抗视角的是「前举 / 下劈」（x 通道）。

### 1) 重档：加袖骨（不新造袖子）
袖子几何（`sleeve` / `forearm_silk` / `cuff_lace`）本来就在，只是**死绑在 `arm_*` / `forearm_*` 上**。新增两条袖骨/侧：根段 `sleeve_*`（绕肘）、子段 `sleeve_*2`（绕腕），把原体块改挂上去 —— rest 零旋转 ⇒ 静止姿态与改造前逐 texel 一致。

袖子甩动复用 `cloth_chain` 的链式写法（`sleeve_chain()`）：**配比 0.55**（面纱是 0.40，缎子比纱硬）、**滞后 0.12s**。

图集**仍然 128×128，没有扩**：`TEX_W = 128` 是设计约束（1u = 1px = 原版皮肤密度，模型高 128u ⇒ 图集正好 128px）。袖口靠省法腾 UV：喇叭口压成**一圈**、只有正/背面用专属蕾丝、侧/内走共享图元 `@lining`（新增 UV ~1280 → ~200 texels）。

袖口位置也是量出来的：腕口那圈落在 y 11.4–12.6，而**腰身半宽 4.0–4.3u、裙摆上沿正好 12.6** ⇒ 被裙摆吃掉。改放到**肘部**做钟形袖（内壁 3.7u 让开 y≈15 处躯干半宽 3.2u，外壁张到 6.5u）。
