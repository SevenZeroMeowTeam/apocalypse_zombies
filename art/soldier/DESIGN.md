## 2. 坐标与尺度铁律（沿用项目规范）

- **16u = 1Block**，即 **1u = 1px = 6.25cm**；贴图 **128×128**，1u = 1px。
- 模型**面朝 -Z**，上 +Y，右 +X；凡 `_r` 必在 x>0、`_l` 必在 x<0（`_r` 是角色右手边）。
- rest 姿态**全部骨骼零旋转**；显隐只用 scale 0/1；动画绝不写 scale 通道。
- 脚底 y=0，头顶 ≈ 32.4u ≈ **2.03 方块**（命中盒按 `0.6F × 2.0F` 注册）。

## 3. 骨骼树（23 根）

```
root                 ← 不参与动画的挂点
└ hip (0,13,0)       ← 骨盆；腰带/口袋挂在这
  ├ spine (0,13.4,0) ← 腹部
  │ └ chest (0,18.6,0)   ← 胸/肩；马甲、肩带、箭袋挂在这
  │   ├ neck (0,25.4,0)
  │   │ └ head (0,26.6,0) ← 头盔挂在这
  │   ├ arm_r (5.2,23.5,0) └ forearm_r (5.2,17.5,0) └ hand_r (5.4,12.4,0)
  │   └ arm_l (-5.2,23.5,0) └ forearm_l (-5.2,17.5,0) └ hand_l (-5.4,12.4,0)
  ├ leg_r (2,13,0)  └ shin_r (2,6.5,0)  └ foot_r (2,2,0)
  └ leg_l (-2,13,0) └ shin_l (-2,6.5,0) └ foot_l (-2,2,0)
```

## 4. 两种变种（同一套模型/骨骼）

| 变种 | 形象差异 | 手里的东西 | 行为 |
|---|---|---|---|
| `ARCHER` 弓手 | 贴图偏冷绿、箭袋更满 | 原版弓（`Items.BOW`，走 `ItemInHandLayer`） | 拉弓射箭 |
| `SAPPER` 爆破兵 | 贴图偏土褐、胸前多一个炸药包 | 点燃的 TNT（`Blocks.TNT` 物品） | 点燃后抡臂抛出**已点燃的 TNT** |

变种差异**只走贴图 + 手持物 + 行为**，不拆模型：这样动画、骨骼、命中盒完全共用一套，
调一个变种的手感不会牵动另一个。

## 5. 动画清单

| 剪辑 | 长度 | 说明 |
|---|---|---|
| `idle` | 2.4s 循环 | 驼背微晃 + 呼吸起伏 + 头缓慢左右扫视 |
| `walk` | 1.6s 循环 | 拖步：膝盖抬得低、脚掌贴地拖、躯干左右摇 |
| `attack` | 1.0s 非循环 | 近战：右臂后摆 → 前抡（僵尸式直臂拍击） |
| `shoot_bow` | 2.2s 非循环 | 举弓 → 拉弦到满（0.7s→1.4s 后拉到最大）→ 放弦回弹 |
| `throw_tnt` | 2.0s 非循环 | 掏弹 → 后仰蓄力 → 大臂过顶抡出 → 收招 |
