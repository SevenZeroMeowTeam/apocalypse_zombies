### 为什么 1.1.27 的结论被推翻

1.1.27 判定「后掠必须把整套前段总成刚性后移」。重读解算器后发现真正的问题不是几何，而是**建模假设**：
旧版是「先指定屈曲角 `FLEX_MAX` → 再解出臂长变化 `slide`」—— 梢部一后掠，弦心后移就要求臂长被拉伸
（实测 1.95u），自检的 0.35u 阈值必然拦住，于是「后掠不可行」是那个假设的必然产物，不是物理事实。

改成**两个不变量定位置**（弦长恒定 + 臂长恒定 ⇒ 两圆交点）后：**臂长是常量、屈曲角是输出**，
滑移恒为 0，后掠随之解锁 —— 弓片座 / 箭道 / 握把一个都不用动。

### 踩到的坑（务必记住）

解算器返回的屈曲角必须按生成器内部约定**取负**（`limb_dir` 用 `ph = ph0 − deg`）。
首版直接返回方向角变化量，动画里写进去的旋转方向是反的 ⇒ 梢部朝**前**转、弦两段内端分离 0.53u、
弦心落不到牙上。**是自检拦下的**（`draw 拉满弦心未落牙`）—— 这条路上没有自检会死得很难看。

### 「加大后掠角」为什么没做（实测否决，非调参问题）

把梢部 z 后掠以贴合参考图的长后掠弓臂，被生成器自检否决。根因：
**弦的半段长是从「弦心（牙）」量到梢部的常数 4.55u** —— 拉满时弦心后移，梢部必须沿臂轴滑移
才能维持该长度，而滑移量对「梢部方向相对 x 轴的夹角」极其敏感。
原设计梢部**向前甩 −11.4°**，恰落在残差极小点上（0.28u）；一旦后掠，转动会把梢部整个往内带，
x 损失由 0.25u 涨到 1.27u，滑移补到 1.95u ⇒ 视觉上等同弓臂被拉伸（阈值 0.35u）。

| 梢部 z | 拉程 2.4u | 2.8u | 3.2u |
|---|---|---|---|
| **−7.30（原值）** | 0.305 ✓ | 0.282 ✓ | **0.214 ✓** |
| −7.10（后掠 0.20u） | 0.446 ✗ | 0.427 ✗ | 0.362 ✗ |
| −6.95（后掠 0.35u） | 0.558 ✗ | 0.544 ✗ | 0.482 ✗ |
| −6.65（后掠 0.65u） | 0.801 ✗ | 0.799 ✗ | 0.750 ✗ |

**真正的后掠**必须把「弓片座 + 箭道槽 + 牙」整套**前段总成刚性后移**（相对几何不变 ⇒ 滑移不变 ⇒
自检仍过），但箭道后端会撞上握把（握把前柱 z −4.00），需连后段总成一起重排并使全枪变长 —— 未做，待定。

搜索脚本：`tools/_search_sweep.py`（网格扫描常量 → 跑真生成器 → 解析「臂轴滑移 ≤X」与失败条数）。

### 症状与根因

用户报「模型不完整、错位」。取证结论：**同一个根因**。

`tools/crossbow_v2.py` 的 `cam_wheel()` 用偏心椭圆建凸轮：

```
r = CAM_R0 + CAM_DR * cos(a)        # a = 0° 处取极大
xc, zc = cx + r*cos(a), cz + r*sin(a)
```

`cos(a)` 在 a=0° 取极大 ⇒ **鼓包恒指向 +x**。于是：

* 右轮（cx=+4.42）鼓包**朝外** —— 符合真实复合弩；
* 左轮（cx=−4.42）鼓包**朝内** —— 错。

同时 4 根辐条（26/112/198/292°）、弦槽凸榫（−40°）、副缆柱（140°）全部按**绝对角度**摆放，
`do_limb()` 也是左右各自用 `±sgn` 独立算一遍抛物线弧（差 0.01u）。
⇒ 左右两侧是**平移副本**而不是镜像，两个凸轮是**两个不同形状的轮子**：

| 指标 | 改前 | 改后 |
|---|---|---|
| 凸轮 74 块里找不到镜像对应 | **46 块** | **0 块** |
| 最大坐标差 | **0.14 u** | 0 |
| 左轮 x 起点 / 右轮 x 起点 | −4.905 / −5.045 | ±5.045 对称 |
| 同位置块尺寸 | 0.292 vs 0.096（完全是两个块） | 逐块一致 |
| 弓臂 9 块里不成镜像 | 6 块 | 0 块 |
| 整机 x 包围盒 | −4.91 .. +5.04（中心偏 0.065） | −5.045 .. +5.045（中心 **0.000**） |
| 总宽 | 9.11 u = 57.0 cm（README §6.2 记为已知偏差） | **10.09 u = 63.1 cm** |

「不完整」与「错位」来自同一个病：左轮的弦槽凸榫与副缆柱**指向枪身内侧**，
主弦/副缆看起来接在不存在的东西上，轮子像缺了一块。README §5 本来就写明凸轮
「按弦自凸轮内侧放线取的手性（左 +140°、右 −140°）」—— **手性本来就是设计意图，
只是几何一直没做**。

### 修法

生成器新增 `mirror_side(src, dst)`：把 `_r` 侧几何按 x=0 平面**精确镜像**成 `_l` 侧
（不是平移副本），在写出层之前执行：

* `origin.x → −(origin.x + size.x)`，`size` 不变；
* `pivot.x → −pivot.x`（GeckoLib 支持 cube 级 pivot，凸轮各辐条绕各自枢轴转，必须一起镜像）；
* `rot → (rx, −ry, −rz)`（过 x=0 平面的反射把 Y/Z 转角取反，X 不变）；
* 归属骨改成目标骨（第一版漏了这一步，74 块镜像全写回 `cam_r`，副本翻倍 ⇒ 生成器自检 exit 1）。

调用：`mirror_side('cam_r','cam_l')`、`mirror_side('limb_r','limb_l')`。
弦/副缆本来就是精确镜像，未动。

### 验证

* 生成器自检「全部通过」（含弦长/缆长恒定解算 —— 证明镜像没有破坏运动学）；
* 四对左右部件 1:1 配对：弓臂 9/9、凸轮 74/74、弦 2/2、副缆 1/1，不成镜像 **0** 块；
* 动画逐字节未变；体块 501 / 骨骼 21 不变；静止剪辑 5 条通道不变；
* `tools/_deploy_126.py` 全部断言通过，`build/libs` 与 mods 内 jar md5 一致。

### 顺带修的工具缺陷

`tools/model_preview.py` 原先只按高度自适应取景（`scale = H*0.82/(top-bot)`），
扁长物品（弩 14.9u 长 × 4.87u 高）会被横向撑出画框裁掉 —— 之前判读十字弩渲染图
出过的错就是它造成的。现改为**同时受高度与水平外接半径约束**（用 XZ 外接半径，
与 yaw 无关，任何视角都不出框）；对高瘦模型（美女僵尸）结果不变。

## 预览工具符号约定复核（2026-09-27，用户报「弦朝内不是朝外」）

### 结论：模型没错，预览工具错了

用户看 `_v_side.png` / `_v_draw.png` 判断「弦被放到弓的前方（向外）」。逐条取证后定性为
**`tools/model_preview.py` 的符号缺陷** —— 几何与动画数据自始正确，未动一个字节：

| 证据 | 内容 |
|---|---|
| GeckoLib 4.8.4 字节码 | `javap -p -c` 解本机 `geckolib-forge-1.20.1-4.8.4.jar`：`RenderUtils.rotateMatrixAroundBone` 依 Z→Y→X 顺序 mulPose，**rot 原样传入、一个都不取负**；`core/animation/*` 把 `BoneSnapshot` 的 rot 直接写进 `GeoBone` |
| MC 1.20.1 字节码 | `joined-1.20.1-20230612.114412-srg.jar` 内 `com/mojang/math/Axis.class`：`<clinit>` 把常量绑到 `Quaternionf.rotationX/Y/Z(+angle)`（右手系，+Y 把 +X 转向 −Z），取负的那三个只被 `XN/YN/ZN` 用到 |
| 数据侧（世界坐标） | 满弦后弓臂梢 **x 4.63→4.37、z −7.67..−5.98 → −7.21..−4.94**（向内 + 向后收）、凸轮中心 z **−6.20 → −5.12**、弦内端 **(±0.011, 0.936, −3.399)** = 挂机点前一弦厚 ⇒ 弦确实是**朝内**走的，与那批镜像图正好相反 |
| 工具自身 | 原码 `rx, ry, rz = -rot[0], -rot[1], rot[2]`，注释还声称「动画 JSON 的 x/y 取负再转弧度」—— 无任何来源，纯属想当然 |

### 修了什么（均在 `tools/model_preview.py`）

* `rx, ry, rz = rot[0], rot[1], rot[2]`（原为 x/y 取负），注释改为「本机 jar 字节码」依据；
* `chan_at()` 增加 `default`：剪辑缺某旋转通道时回落到**骨的 geo 静止旋转**（GeckoLib 每帧先恢复
  基线再叠键），原来硬取 `[0,0,0]`，把弓臂预弯角吃掉；
* **`--selftest` 守门人**：用工具自身的变换复核「满弦弦内端落在爪面」—— 偏差 **0.099 u**
  （= 弦方块半厚 0.05 + 弦芯豁口）通过；把旧取负塞回去得 **5.97 u** 失败。容差 0.18 u；
* `View.to_screen` 的屏幕 x 补上取负（与 `render()` 的 `ox − p[0]*scale` 一致；原先差一个水平
  镜像，按它算裁图框会裁到镜像位置 —— 本次裁图踩过一次）；
* `render()` 面列表补带**骨骼名**，并新增 `tint={骨: RGB}` 染色通道（原先面列表不带骨名，
  按骨骼染色会全部串成外层循环泄漏的最后一个骨的颜色）；
* 新增 `tools/crossbow_draw_diag.py`：弓部按功能染色的「静弦 / 半拉 / 满弦」三联诊断图
  （弓臂绿 / 凸轮蓝 / 弦红 / 缆橙 / 挂机勾爪黄 / 弓座紫），贴图偏暗看不清时用它判读方向。
