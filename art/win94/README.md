# win94（温彻斯特 M1894 杠杆步枪）—— 参考图判读与真枪文献基准

## 本轮（v2）重做的原因

上一版把真枪机构读错了三处，用户指出的正是这些：

1. **环做成了一个**（v1 的脚本把扳机护圈删了，只留杠杆环）。真枪机匣下方是**两个环**：
   前面的**扳机护圈**（小、固定、包住扳机）+ 后面的**杠杆环**（大、横向拉长、随杠杆摆），
   关闭时上下相接，侧面看成"8"字。
2. **装填门装在了机匣尾端**（z +0.02…+0.34）。真枪在中后部（z −1.63…−0.88）。
3. **倍镜架得不够高**。M1894 是**顶部抛壳**，镜子必须架高才不打壳；本版镜管中心抬到
   bore 上方 50 mm，镜管底与机匣顶留 27 mm 抛壳净空。

另外 `carrier` 的进弹顺序在 v1 里改过一版仍然要盯住：**先下摆接弹、再抬起送弹**，
一开栓就抬起等于把还没出弹仓的子弹抬到膛口（现在由 `gate.py` 的三条断言卡死）。

## 坐标与单位（项目铁律，见 `docs/wiki/05-武器制作流程.md`）

- 16 u = 1 方块；**1 u = 62.5 mm**；1 in = 25.4 mm = 0.4064 u
- 枪口 −Z、上 +Y、**+X = 射手右侧**（装填门与抛壳口都在 +X 侧）—— 这是**作者空间**（bbmodel / spec.py）
- 原点 = 机匣中心（膛线轴线 bore 在 y = 0）
- ⚠ **两套空间**：落盘的 `geo.json` / `animation.json` 是空间 F（装填门等不对称件在 −X 侧，
  wiki 07「导出空间 −X = 射手右侧」）；GeckoLib 加载时把 F 预烹饪回**作者空间 B**
  （位置 x → −x；旋转 (rx,ry,rz) → (−rx,−ry,+rz)；三处源码见 `export.py` 文件头）。
  换算由 `export.py` 的 `cook_for_export()` 统一完成，**Blockbench 里改动画写 B 空间值，
  不许手翻、不许手改落盘文件**。教训：漏换算 → 子弹从装填门对侧压入（1.1.105 前）；
  旋转换算方向写错 → 杠杆在实机向上翻（1.1.106，1.1.107 修）。

## 真枪基准 → 模型尺寸

取 **Winchester Model 1894 Rifle，24 英寸枪管**（.30-30/.32 同族外形；本模组按 .45-70 设定弹道）。

| 部位 | 真枪数据 | 模型（u） | 说明 |
|---|---|---|---|
| 全长 OAL | 43.6 in ≈ 1108 mm | 17.83 u = 1114 mm | 与真枪同长 |
| 枪管（外露） | 24 in = 610 mm | 8.00 u | 八棱管近似圆管，Ø 0.33 u = 20.6 mm |
| 机匣 | 长 7.2 in / 宽 1.4 in | 3.02 × 0.58 u | 高 0.94 u（含顶部 tang） |
| 管状弹仓 | 枪管正下方，Ø ≈ 15 mm | Ø 0.24 u，中心 bore 下 0.30 u | 六棱管；容量 5 发（`Win94Item.MAGAZINE_SIZE`） |
| 木质护木 | 长 ≈ 230 mm、宽 1.3 in | 3.68 × 0.51 u | 上缘贴枪管下 |
| 枪托 LOP | 13 in = 330 mm | ≈ 5.3 u | 托背近水平、托腹向后下斜 |
| 托底 drop | heel 75 mm / toe 194 mm | −1.20 → −3.12 u | bore 相对高度 |
| 托底板 | 高 4.8 in = 122 mm | 1.98 u | 月牙钢托 |
| 闭锁块行程 | ≈ 2.4 in = 61 mm | **0.98 u** | 必须 ≥ 弹壳长（.30-30 壳 2.04 in）才抽得出壳 |
| 杠杆全开角 | 真枪 60–70° | **62°** | 环在转轴后方 ⇒ 绕 X 轴**正角度** |
| 倍镜 | 1" 管、物镜 Ø 42 mm、长 411 mm | 镜管 Ø 0.41 u、长 6.58 u、中心 y 0.80 u | 顶装高架，抛壳净空 27 mm |

## 机构时序（杠杆循环相位表）

把 lever 的全行程记作闭锁块（bolt）0→100%→0：

| bolt 行程 | 动作 |
|---|---|
| 0–10% | lever 下扳，闭锁凸榫脱离机匣（**开锁**） |
| 10–35% | 闭锁块尾部压下击锤 → **待击**（M1894 是 cock-on-opening，发生在开栓段） |
| 35–65% | 抽壳钩带壳后退，弹壳脱离弹膛 |
| 60–80% | 壳尾撞机匣侧 ejector，空壳**向右上方**抛出 |
| **55–75%** | **carrier 这时才下摆**（闭锁块后退的后半段）；弹仓弹簧把下一发顶到 carrier 顶面 |
| 75–100% | carrier 全下位接弹；其前端兼作 cartridge stop 挡住后面的弹 |
| 回程 0–25% | lever 凸轮**先抬起 carrier**，把子弹送到膛口高度（抬升略领先闭锁块面） |
| 25–85% | **闭锁块面推弹入膛** |
| 85–100% | 闭锁块到位、凸榫闭锁、击锤被 sear 扣住 |

⚠ 顺序别写反：carrier 是"**先下后上**"。`tools/win94/gate.py` 会检查
"最低位时刻必须落在闭锁块全退行程的后半段、且早于最高位时刻"。

**换弹是"装填门逐发压入"，不是换弹匣**：管状弹仓 + 机匣右侧弹簧钢装填门，子弹压进去时把
钢片顶开、弹进仓后钢片回位；管仓满 5 发后还要扳一次杠杆把第一发送进膛 —— 这是
`reload_empty`(4.4 s) 比 `reload_tactical`(2.2 s) 长的原因。

**退弹**同理：反复扳杠杆逐发抛出。

## 脚本体系（本轮重写，取代 v1 的一堆补丁脚本）

旧的 `win94_gen2/apply/anim3/paint2/paint3/rebuild/redesign2/fix1/...`
已移到 `tools/_legacy_win94/`。现在只有一套：

| 文件 | 职责 |
|---|---|
| `tools/win94/spec.py` | **唯一的数字来源**：真枪基准、骨骼树、机构常量、材质、契约名 |
| `tools/win94/model.py` | 几何生成器（管/环/连通环 + UV 货架 + 共面自愈）→ `build/win94/*.json` |
| `tools/win94/build.py` | 经 MCP 清空并重建（ensure → clear → groups → cubes → verify） |
| `tools/win94/tex.py` | 按 UV 表逐面绘制 512² 贴图并经 MCP 装入（木纹/钢纹按**模型坐标**画，跨段连续） |
| `tools/win94/anim.py` | 7 条 clip 的关键帧表（真枪相位）+ 写入 |
| `tools/win94/export.py` | save_project → identifier → export geo → 本地转 animation.json（**动画在该步做 X 镜像**：作者空间 → 导出空间，含 `check_mirrored()` 校验） |
| `tools/win94/gate.py` | 门禁：环闭合/护圈包扳机/装填门位置/镜高/动画相位/资源完整性 |
| `tools/win94/all.py` | 一键全链路（同进程依次调用，沙箱下不 spawn 子进程） |
| `tools/win94/shot.py` | 固定机位截图（目视核对用） |

常用命令：

```
python tools/win94/all.py          # 几何 → Blockbench → 贴图 → 动画 → 导出
python tools/win94/gate.py         # 门禁
python tools/win94/shot.py side iso lever action
```

## 与 Java 侧的契约

- 骨骼名（16）：`root/move/body/barrel/forearm/receiver/stock/bolt/hammer/lever/carrier/`
  `cartridge/spent_shell/trigger/gate/scope` —— `Win94ItemRenderer` 硬编码 `move` 与 `lever`。
- clip 名与 tick：`static_idle 40 / draw 16 / shoot 12 / bolt 22 / reload_tactical 44 /`
  `reload_empty 88 / inspect 52`（Java 侧 `SHOOT_TICKS` 等常量 + `check_gun_resources.py` 卡）。
- 第一人称手部目标写在 `Win94GeoModel.java`：`GRIP / SUPPORT / LEVER_KNOB / LEVER_TURN_MAX`
  随模型改动同步（本轮已按新几何更新：握把 y −0.85、环底 (0, −2.17, 0.92)、摆角 62°）。

## 已知缺陷与限制

诚实清单（哪些是取舍、哪些是还没验的），改动这一段时请同步核对：

| # | 缺陷 / 限制 | 说明 |
|---|---|---|
| 1 | **动画没有肉眼验收** | MCP 的截图通道**看不到骨骼变形** —— `preview_animation` / `screenshot` 渲染的是未变形的静态几何，所以 7 条 clip 目前只有数据验收（关键帧值、相位顺序、tick 契约，见 `gate.py`）。要肉眼确认得在 Blockbench 里拨时间轴，或进游戏看。 |
| 2 | `ADS_X / ADS_Y` 还是借 Mosin 的 | `Win94GeoModel` 里 −0.475 / 0.37 是从 Mosin 抄的；模型长度从 21.9 u 缩到 17.83 u 之后没有重测。要用 `tools/pose_measure.py` 重新量。1.1.106 起 `hidesModelWhileAimed() = true`（右键瞄准隐藏手和枪），这组值只影响抬枪可见的前半程（`SCOPE_HIDE_MODEL_AT = 0.5` 之前），偏一点也不再看得出来。 |
| 3 | 枪托 / 护木是**分段方块**拼的 | 枪托 24 段、护木 4 段，侧面轮廓仍是阶梯（每段 ≈5 mm 落差），不是连续曲面。再加段数会显著推高方块数（现在 249）。 |
| 4 | 圆柱是**多棱近似** | 枪管 8 棱、弹仓管与镜管 6 棱、卡箍 12 段。凑近能数出棱面。 |
| 5 | 环是**弦直条搭接**的 | 杠杆环 20 段 / 护圈 16 段，段间搭接 10%，放大看有轻微棱角；实测最大缝 1.62 mm（`gate.py` 卡 3 mm）。 |
| 6 | 抛壳口 / 装填门是**贴片**不是真镂空 | 机匣右壁的开口用薄壁块拼出来、装填门贴在凹槽里，没有做真正的空腔。 |
| 7 | 木纹是**程序生成**的 | 按模型坐标画年轮线（跨段连续），但不追真实木料纹理；同一张贴图在枪托与护木上重复。 |
| 8 | 弹仓容量 **5 发** | 模组设定（`Win94Item.MAGAZINE_SIZE`）。24 英寸管 rifle 真枪常见 8+1。 |
| 9 | 内部机件只有**平动** | 闭锁块、升降器（carrier）只在机匣内平移，没有做闭锁凸榫摆动、抽壳钩张合这类细节动作。 |
| 10 | 倍镜是**顶装高架**一种形态 | 真枪因顶部抛壳常用侧装或 scout 长眼距；本模型取等价的顶装高架（bore +50 mm），没做偏置 / 侧装变体。 |
| 11 | 未在游戏内实机验证 | 本轮只跑到"导出资源 + 门禁全绿"；实机表现（持枪姿势、第一人称位置、音效拍点）需要进游戏确认。 |
