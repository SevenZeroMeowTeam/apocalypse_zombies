# Apocalypse Zombies · Scorched 资源包

末日风方块材质包，两套分辨率：

| 文件夹 | 分辨率 | 适用 |
|---|---|---|
| `apocalypse_16x/` | 16×16 | 原版观感、低配友好 |
| `apocalypse_32x/` | 32×32 | 更细的裂纹与噪点 |

两套都是**直接用**的完整资源包，不是模板：`pack.mcmeta`、`pack.png`、全部方块贴图都齐了。

## 画风

- 冷灰的裂石、被烧过的泥土、灰烬与锈迹、枯黄的草皮、稀疏的枯叶；
- **植被贴图烘焙了光照**（草皮、枯木与 9 种树叶都算）：统一假想光源在左上，每片叶簇/每根草叶
  按球冠法线算受光量，迎光轮廓补一道暖灰微高光、背光侧压暗，再按绘制高度补一层环境遮蔽 ——
  被高处围住的像素变暗。所以叶簇有受光面、背光面和层叠阴影，而不是一块均匀色斑；
- **9 种树叶共用同一套明暗规则与调色板纪律**（枯黄、去饱和、偏暖灰，不用荧光绿），靠色调、
  叶簇形状、簇密度与透光覆盖率区分针叶与阔叶；两套分辨率的叶覆盖率取同一个目标值，
  16x 与 32x 只看密度不会走样；
- 矿石带暗色结壳与荧光矿点；黑曜石/深层岩偏紫黑，呼应模组的末日紫主题；
- 玻璃是带裂纹的脏玻璃；工作台/熔炉是烧旧、熏黑的木与石；
- 所有贴图都按方块可平铺绘制（seamless），随机种子固定，重复生成结果一致。

## 16x 全量内嵌进模组（6.2.0 起）

16x 包的整套方块贴图（73 张）在构建时会被复制进 mod 自己的
`assets/minecraft/textures/block/`（见 `build.gradle` 的 `scorchedBlockTextures`），
**只装模组、不装资源包**的玩家也能看到完整的 Scorched 世界，不再残留官方方块材质。

- Forge 的 mod 资源包优先级高于原版、低于用户资源包：装了 `apocalypse_32x`（或任何资源包）的
  玩家仍然看到自己那一套，不会被内嵌的 16x 顶掉；
- **只内嵌 16x**。32x 是「想更好看就自己开」的选项，不该悄悄把模组做胖；
- 内嵌 = `textures/block/` 整目录搬运（无名单，新增贴图自动随 jar 走）；1.13 前旧路径
  `textures/blocks/` 不内嵌，1.20.1 不读。

## 安装

1. 把 `apocalypse_16x`（或 `apocalypse_32x`）整个文件夹放进
   `.minecraft/resourcepacks/`（也可以把它们分别压缩成 zip 再放进去）；
2. 游戏内 **选项 → 资源包**，把它移到右侧「已选择」并点完成；
3. 若游戏提示「为旧版本制作」，直接点「仍然加载」即可。

## 版本兼容

- `pack_format` 写的是 **15**（1.20.1 的格式），同时带 `supported_formats: 4–99`；
  - **1.20.1** 与 `pack_format` 精确匹配 → 进游戏自动生效，不需要点「仍然加载」；
  - **1.20.2+** 改读 `supported_formats`，仍落在可接受区间内；
  - **1.13–1.20.0** 只认 `pack_format`，会显示「为旧版本制作」，需在资源包界面点一次「仍然加载」。
  > 早期版本写的是 4，实测在 1.20.1 上会被判为不兼容并**从 `options.txt` 里被移除**
  > （日志：`Removed resource pack file/apocalypse_16x ... no longer compatible`），
  > 因为 1.20.1 根本不读 `supported_formats` —— 所以基准版本必须写成 15。
- 包内同时放了两套路径：
  - `assets/minecraft/textures/block/` —— 1.13+ 的扁平化文件名；
  - `assets/minecraft/textures/blocks/` —— 1.12 及更早的旧文件名。
  因此同一份包在 1.6.1–1.12 与 1.13+ 都能找到贴图。
  - 树叶的旧名沿用 1.12 的叫法：`oak_leaves → leaves_oak`、`spruce_leaves → leaves_spruce`、
    `birch_leaves → leaves_birch`、`jungle_leaves → leaves_jungle`、
    `acacia_leaves → leaves_acacia`、`dark_oak_leaves → leaves_big_oak`（1.12 就叫 big_oak）；
    1.12 没有的三种（`mangrove` / `azalea` / `cherry`）按同一规则补成
    `leaves_mangrove` / `leaves_azalea` / `leaves_cherry`。
- 1.13–1.20.0 与 1.12 及更早如果启动器把包标成不兼容，把 `pack.mcmeta` 里的 `pack_format`
  改成对应版本，或者直接在游戏里点「仍然加载」。对照表：
  1.6–1.8 = 1，1.9–1.10 = 2，1.11–1.12 = 3，1.13–1.14 = 4，1.15–1.16.1 = 5，
  1.18–1.18.2 = 8，1.19–1.19.2 = 9，1.19.3 = 12，1.19.4 = 13，**1.20–1.20.1 = 15**。

## 重新生成 / 改色

```bash
python resourcepack/tools/generate_textures.py
```

- 调色板在脚本各 `def` 里（`rgb('#...')`），改一处就能换整块材质；
- 想加新方块：在 `MODERN` 字典里加 `名字: 函数`（1.13+ 文件名），
  旧版映射加在 `LEGACY`（旧文件名 → 新文件名）；
- 16×32 两套由同一个脚本按 `size` 生成，改完一次运行两套一起更新；
- 植被的画法集中在「植被（烘焙光照）」一节：`LIGHT_X/LIGHT_Y` 是假想光源方向，
  `HIGHLIGHT` 是迎光面的暖灰上限（防止高光烧白），`_clump` 画叶簇、`_occlude` 补环境遮蔽、
  `_thin_to` 把覆盖率削到目标值；9 种树叶之间的差异全在 `LEAF_STYLE` 表里（色调、簇大小与
  形状、密度、边缘疏松度、目标覆盖率、是否针叶）；
- **植被用独立随机源**（`texture_rng`，种子 = 分辨率 + 贴图名），所以改一种植被的画法只会动它自己；
  其余 61 张贴图仍走原来那条共享随机流、按原来的顺序取数，因此本次重做**没有改动它们任何一个像素**；
- `tools/_legacy_stream.py` 是**冻结件**：里面逐字保留了旧版那 4 个植被实现（`grass_top`、
  `grass_side`、`leaves`、`dead_bush`），唯一职责是在原来的位置上把共享随机流推到它历史上该在的位置，
  **产物丢弃、不写盘**。单流是有状态的：植被一旦不再从它取数，排在它后面的 57 张非植被贴图的起点
  就会整体平移、全部换上另一套噪点。所以那个文件只复现历史、不跟随画风，**不要改、不要优化、不要删**。
