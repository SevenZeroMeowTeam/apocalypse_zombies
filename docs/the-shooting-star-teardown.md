> **注意：本文是参考包的拆解和 1:1 对照，只作资料，不是我们的正式方案。**
> 我们的原创打击引擎与六种“末日协议”设计见 `docs/strike-engine-design.md`。

> 本文只做**内容与系统设计**，不复制参考包的代码、贴图、音效或字体。参考包的完整拆解见其

## 0. 一句话结论

参考包最值得学的不是 shader，而是它的**内容公式**：

> **一种打击 = 一个独立幻想 + 一部独立电影 + 一个独立地形签名 + 一段可以回去看的余波。**

本模组现有六种弹种，正好可以对齐参考包的六个 Stellar Remote 技能（SS-01 ~ SS-06）。
我们要做的不是“再叠一层特效”，而是把六种弹种各自做成**不可互换的一击**：

| 本模组弹种 | 新身份 | 参考技能 | 一句话幻想 |
|---|---|---|---|
| CANNON 轨道炮 | **SS-01 · THE SHOOTING STAR** | The Shooting Star | 从银河边缘打下来的红色轨道炮，把整列世界挖到虚空 |
| LASER 宇宙激光 | **SS-02 · MERIDIAN** | Meridian（正式版） | 轨道镜阵把一条“子午线”烙过地表，切出一条贯穿地平线的沟 |
| LANCE 天基长矛 | **SS-03 · GUNGNIR** | Gungnir | 在木星加速环里转七圈的黑色长针，先静默落地，再传来音爆 |
| STORM 等离子风暴 | **SS-04 · SEVEN STARS** | Seven Stars | 北斗七星投到地面，七颗星依次落下，最后把星座连线烧成沟 |
| GRAVITY 引力奇点 | **SS-05 · TESSERACT** | Tesseract | 彩虹光笼把地面切成 64 格，四波把地块连根拔起、翻上天空 |
| PLANET 行星陨落 | **SS-06 · ORRERY** | Orrery（正式版） | 一座天球仪在天空展开，行星脱离轨道砸下来，留下环形抛射带 |

保留我们现有的名字作副标题（“轨道炮”“宇宙激光”……），但**玩法、电影、地形、声音全部按上表重做**。
这样玩家在遥控器上看到的不是“六种伤害参数”，而是六个完全不同的仪式。

## 1. 参考包拆解：它为什么“有打击感”

### 1.1 内容结构

参考包的四个 demo 技能各自有独立的服务端时间轴、客户端电影、专属 shader pass 和音效表：

- **SS-01 轨道炮**：`star/j.java` 时间轴（标记 31t → 破坏 352–486t → 结束 526t），
  电影 `client/cinematic/h.java` 共 564t，`client/fx/p.java` 有 0/7/9/29/44/238/314/352/462/490t
  十个音效 cue；命中后 800t 余烬。
- **SS-03 冈格尼尔**：`star/e.java`（标记 31t → 静默 290t → 落地 322t → 冲击环 322–358t），
  电影 `client/cinematic/e.java`（0/8/28/44/62/300/322/341 等镜头段），
  音效 cue：0 开保险、7 按钮、9 余烬标记、29 升空、44 离地、124 加速环、146 装针、168 自旋、
  247 释放、256 飞行、290 静默、322 裂空、322+距离延迟的音爆、372 风、之后 800t 嗡鸣。
- **SS-04 七星**：`star/i.java`（7 个节点、290/398/440/470/560t），电影 `client/cinematic/f.java`，
  音效 cue：标记、锁定、升空、阵列唤醒、七次坠落/落地、连线、终曲。
- **SS-05 超立方**：`star/m.java`（290/398/426/438/462/474/562/682t，四波），
  电影 `client/cinematic/k.java`，16 段 `tess_rw_01..16` 无线电台词。

共同点：**每个技能都有一张“时间表”**，不是“一个技能一个粒子效果”。

### 1.2 电影结构（六幕）

参考包的电影几乎都是同一骨架，但每幕的镜头语言不同：

1. **地面仪式**（0–30t）：手持遥控器/镜头贴近手，开保险、按按钮、目标被红/余烬标记。
2. **升空**（30–70t）：镜头从眼位拉起、绕玩家、FOV 收窄；云层/大气被“揉碎”淡出。
3. **太空/装置**（70–300t）：远景建立镜头 → 推近装置（炮/环/阵列/光笼）→ 装填/自旋/对齐。
4. **发射**（300–352t）：静默/倒计时最后几拍 → 装置开火或释放。
5. **命中**（352–400t）：镜头贴近爆点/冲击环；FOV punch、屏幕震动、冲击帧、延迟音爆。
6. **余波/回位**（400–564t）：绕弹坑/装置一圈 → 拉远 → 回眼位；余烬/针体/星核/光笼留下。

SS-01 的镜头表（`cinematic/h.java`）可以当作模板：

- `0–8` 手部特写；`8–30` 绕玩家仰拍、FOV 58→30；`30–46` 后拉、FOV 64→70、roll 0→4；
- `46–72` 升到 +476 格；`72–342` 太空停留；`342–352` 俯冲向光束；`352–374` 贴脸命中；
- `374–422` 绕坑；`422–462` 拉远；`462–494` 高空收尾；`494–564` 回眼位。

这种“先给仪式、再给尺度、最后给后果”的顺序，就是打击感的来源。

### 1.3 声音

参考包每个技能 10–20 个 cue，关键手法：

- **静默**：冈格尼尔在 290t 主动掐掉环境声/音乐，只剩风与心跳；落地先看到冲击环，**音爆按距离延迟**才到。
- **分层**：机械声（保险/按钮/装填/自旋）→ 能量声（充能/环/光束）→ 冲击声（裂空/音爆/风）→ 余波（嗡鸣/余烬）。
- **无线电台词**：超立方 16 段 `tess_rw_*`，把“机器在说话”变成节奏。
- **距离衰减**：远处玩家先看到光，后听到声；近处玩家先被低频打中。

### 1.4 地形签名

参考包真正让人觉得“打中了”的原因是**世界变了**：

- 轨道炮：半径 200 的**整列世界**从 build limit 挖到虚空，边缘灼烧，40s 余烬。
- 冈格尼尔：400 半径的**平面冲击**把地削平到落点高度，中心熔融坑，**一根从世界底部到 build limit 的钨针**留下，可挖回钨/导管。
- 七星：7 个坑 + 7 条连线**沟槽** + 7 颗可拾取的**星核**，最后星座整体燃烧。
- 超立方：8×8 网格、四波把 64 个**整块地块**连根拔起翻上天空，越靠中心越深，留下彩虹光笼/线框超立方。

### 1.5 数据化与 UX

参考包遥控器有：技能菜单、按键绑定、冷却、功率/尺寸/伤害滑条、**速度 0.3×–3×**、
**过场开关**、**过场对附近所有人播放**、**跳过提示**、危险尺寸警告。
这些不是装饰，是让“六种大招”可玩、可调、可重复观看的关键。

### 1.6 明确不照搬

- **全屏 GLSL/FBO 后期管线**（`client/render/d.java` + 30 万字符 shader）：与我们“只用原版
  RenderType、无自定义 shader/FBO、兼容 Embeddium”的约束冲突。
- **Mixin 劫持 Camera/Input/Render**：我们继续用 Forge 事件 + 反射（已有 `OrbitalCinematic`）。
- **参考包的贴图/音效/字体/代码**：第三方资产，不随本模组分发；我们只借鉴设计语言，
  用自己的 2.5D 电影板、程序化几何、原版音效层和原创 OGG。
- **60KB 的多线程世界编辑引擎**：我们保留自己的预算式 Job 队列，按需扩展。

## 2. 六技能设计

> 所有时间以 tick 计（20t = 1s），默认按“紧凑电影”设计；参考包的 18s 长倒计时改为
> `film_speed` / `lock_ticks` 可调，避免玩家在地面干等。

### 2.1 SS-01 · THE SHOOTING STAR（轨道炮 / CANNON）

**幻想**：银河边缘的轨道炮，红色激光先钉住地面，18 秒后一整列世界被抹掉。

- **地面仪式**：遥控器翻盖/按钮；一道**红色目标激光**从天空落到准星位置（世界内可见的细红柱）；
  HUD 显示 `SS-01 · SKYFALL`、距离、半径、倒计时；站在区内会标红。
- **电影**：手部特写 → 拉起 → 太空远景（银河边缘的炮）→ 炮身充能/轨道加速 →
  红色光束沿激光落下 → **镜头骑上弹头俯冲**（关键镜头）→ 命中 → 绕坑 → 回位。
- **视觉**：现有 2.5D 天基炮电影板 + 红色束流；弹头阶段用屏幕速度线/边缘烧红（不用 shader，
  用 HUD 叠层与粒子）；命中用白闪 + 冲击环 + 真实方块粒子。
- **地形签名**：半径 10–1500 的**整列挖穿**（保留现有 ColumnJob）；柱壁灼烧/玻璃化；
  柱底到虚空；命中后 40s 余烬（现有 OrbitalAftermath 扩展）。
- **声音**：开保险/按钮/锁定 → 倒计时（最后 3 拍）→ 升空 → 炮身充能 → 开火 → 光束轰鸣 →
  命中裂空 → 余烬；远处延迟。
- **安全**：生存站区内必死；创造模式自动**evac 传送**到区外（参考包做法）。
- **参数**：半径、伤害、倒计时/速度、是否挖穿、是否保留基岩。

### 2.2 SS-02 · MERIDIAN（宇宙激光 / LASER）

**幻想**：轨道镜阵把一条“正午子午线”烙过地表——不是打一个点，而是**切一条线**。

- **地面仪式**：一条**细光线**从目标向南北延伸（约 128–512 格），像经纬线；天空出现一圈
  轨道镜的闪光；HUD `SS-02 · MERIDIAN`、线宽、长度。
- **电影**：地面线标记 → 升空 → 轨道镜阵展开成一条环 → 镜面逐一转向目标线 → 一条光带
  从地平线一端扫到另一端（约 60t）→ 线心过载白闪 → 回位。
- **视觉**：程序化“镜环”（椭圆/点阵）+ 一条沿线的光带（我们的 line/beam 叠层）；
  扫过时用一条移动的亮头 + 余辉；不用 shader。
- **地形签名**：沿线的**沟槽**（宽 4–16、深 8–64，可配置），沟壁玻璃化/燃烧；
  线心留下一个**圆形玻璃坑**；镜环在天空保留 30s 后淡出。
- **声音**：线锁定（低频）→ 升空 → 镜片对齐（水晶/钟声）→ 充能 → 光带扫过（多普勒）
  → 线心过载 → 余响。
- **差异**：与轨道炮的“点/柱”相反，这是**线/区域封锁**；适合切基地、断路、烧树林。
- **参数**：线长、线宽、深度、伤害、是否留下玻璃。

### 2.3 SS-03 · GUNGNIR（天基长矛 / LANCE）

**幻想**：木星加速环里转七圈的一公里黑针，先静默落地，再传来音爆。

- **地面仪式**：余烬色标记 + 一圈**冲击预告环**（400 半径）；HUD `SS-03 · GUNGNIR`、
  半径、针体落点；倒计时。
- **电影**：手部 → 升空 → **木星/加速环**（可用程序化气态巨行星 + 环，不用参考贴图）→
  环唤醒 → 黑针装填 → 七圈自旋 → 释放 → 长针从天顶落下 → **静默**（掐音乐/环境声）→
  落地裂空 → 冲击环扫过 → **音爆延迟到达**（按距离/340×20t）→ 风 → 回位。
- **视觉**：现有长矛 2.5D 电影板 + 气态巨行星/加速环叠层；针体是一个长条精灵/线段，
  飞行时拉出白色激波；落地后**针体留在世界**。
- **地形签名**：半径 400（可调）的**平面冲击**——把地削到落点高度，中心熔融坑；
  **一根从世界底部到 build limit 的针**（新方块：钨壳/热导管，可挖回）；针体周围灼烧。
- **声音**：标记/倒计时/升空/环/装填/自旋/释放/飞行/静默/裂空/**延迟音爆**/风/针鸣。
  这是六技能里最依赖声音设计的一击。
- **安全**：区内必死；创造模式 evac；针体可挖（不破坏经济）。
- **参数**：冲击半径、针高/是否留针、伤害、静默时长、音爆延迟系数。

### 2.4 SS-04 · SEVEN STARS（等离子风暴 / STORM）

**幻想**：北斗七星投到地面，七颗星依次落下，最后把星座连线烧成沟。

- **地面仪式**：7 个节点 + 连线在目标周围亮起（一个“北斗”图案，尺寸 64–1440 可调）；
  HUD `SS-04 · SEVEN STARS`、节点数、图案尺寸；每个节点独立锁定。
- **电影**：地面星座 → 升空 → 北斗/大熊座星域（程序化星群）→ 七个星阵节点逐一亮起 →
  七颗流星按节点顺序落下（每颗 8–12t 间隔）→ **连线逐条点燃** → 星座整体爆闪 → 回位。
- **视觉**：地面星座用 line/quad 画；流星用现有 ORBITAL_EMBER/火花 + 拖尾；
  连线点燃是一条移动的亮头 + 余辉；星核是一个发光晶体方块。
- **地形签名**：7 个坑（半径按节点亮度）+ 6 条**沟槽连线**（宽 3–8、深 4–16）+
  每坑一颗**星核**（可挖取，掉星屑/用于合成）；最后星座线整体燃烧。
- **声音**：标记/锁定/升空/阵列唤醒/七次坠落+落地（按节点方向声像）/连线/终曲/星核嗡鸣。
- **差异**：**图案/多点**打击，适合清营地、封路；也是我们现有 STORM 的自然升级（5→7 点）。
- **参数**：图案尺寸、节点数（默认 7）、坑半径、连线宽/深、是否留星核。

### 2.5 SS-05 · TESSERACT（引力奇点 / GRAVITY）

**幻想**：彩虹光笼把地面切成 64 格，四波把地块连根拔起、翻上天空。

- **地面仪式**：8×8 网格（尺寸 64–640 可调）+ 七色边框；HUD `SS-05 · TESSERACT`、
  格数、边长；警告“此尺寸可能卡顿”。
- **电影**：地面网格 → 升空 → 天空裂开虫洞 → 超立方机器折叠穿过第四维 → 落在地面网格上 →
  裂缝沿网格跑 → 四波从中心向外把格子抬起（直立/转 90°/倒置/侧立）→ 光笼折叠成线框超立方 → 回位。
- **视觉**：网格/光笼/线框超立方全部用 line/quad 程序化；彩虹色按格分配；
  抬升地块用 FallingBlock/结构捕获（P2 难点）；P0 可先做**分层阶梯坑 + 方块向上飞散**的简化版。
- **地形签名**：64 格、四波、每格**一整立方深**；越靠中心坑越深（阶梯）；格线燃烧；
  中心留下线框超立方/悬浮碎块。
- **声音**：网格锁定 → 虫洞 → 机器折叠 → 落地 → 裂缝 → 四波（每波一次低鸣/碎裂）→
  光笼折叠 → 超立方嗡鸣。
- **风险**：完整抬升 64 个地块非常重；建议 P2 再做完整版，P0/P1 先做“阶梯坑 + 上升碎块 +
  线框超立方”的近似。
- **参数**：边长/格数、波数、深度、是否抬升、是否留线框。

### 2.6 SS-06 · ORRERY（行星陨落 / PLANET）

**幻想**：一座天球仪在天空展开，行星脱离轨道砸下来，留下环形抛射带。

- **地面仪式**：地面出现同心**轨道环**（水星/金星/地球/火星的轨道投影）+ 一个高亮落点；
  HUD `SS-06 · ORRERY`、主星、副星数量。
- **电影**：地面轨道环 → 升空 → 天球仪展开（多个行星 + 轨道环）→ 行星逐颗对齐/点亮 →
  主星脱离轨道 → 进入大气（火尾）→ 主撞击 → **环形抛射/二次陨石** → 天球仪留在天空缓慢旋转 → 回位。
- **视觉**：现有小行星 2.5D 场景 + 程序化轨道环/行星（可复用地/小行星贴图，不新增外部素材）；
  主星用现有 `carrier_asteroid_cutout`；二次陨石用多个小 cutout/粒子。
- **地形签名**：主坑（半径大、浅）+ 环状**二次坑**（4–8 个）+ 抛射射线/熔融环；
  中心可能留一块“行星核”/玻璃。
- **声音**：轨道环对齐（钟声）→ 释放 → 大气进入（低频轰鸣）→ 主撞击 → 二次撞击（按距离延迟）→
  天球仪余响。
- **差异**：**多体/轨道**打击，视觉最壮观；也是现有行星陨落的自然扩展。
- **参数**：主星尺寸、副星数量、坑半径、是否留行星核、天球仪停留时长。

## 3. 统一电影导演系统

我们不再为每个技能写死一条 `lock/fall` 时间轴；改为**一部电影 = 若干镜头段 + 相位事件**。

### 3.1 数据结构

```java
record ShotFrame(Vec3 position, Vec3 look, float fov, float roll) {}
record ShotSegment(int start, int end, int blendInTicks, ShotPath path) {}
record FilmPhase(String name, int start, int end) {}  // mark/ascent/device/fire/impact/aftermath
```

- `ShotPath` 是 `(anchor, t, easedT) -> ShotFrame` 的函数（参考包 `cinematic/g.java`）。
- 镜头段之间按 `blendInTicks` 做 cubic/smoothstep 过渡；整部电影有 `speed` 倍率（0.3–3×）。
- 锚点提供器：玩家眼位、目标点、天空/装置点、弹体位置（用于“骑弹头”）。
- 遮挡：从眼位向机位 ray-march，被方块挡住时缩短机位（参考包 `cinematic/d.java` 做法；
  我们的轨道机位很少被挡，但回位/低机位需要）。

### 3.2 相位与现有代码的对接

- `OrbitalStrikeManager` 仍负责服务端权威（锁定/下落/命中/挖地/伤害），但把**相位事件**
  通过 `OrbitalStrikePacket` 发给客户端（或客户端按同一份电影定义计算）。
- 新 `client/render/film/StrikeFilmDirector` 替换 `OrbitalCinematic` 里写死的时间线；
  现有 `OrbitalCarrierPlates`、`OrbitalScreenFX`、`OrbitalStrikeHighlighter` 改为读相位：
  - `mark`：地面标记/HUD/倒计时；
  - `ascent`：镜头拉起、云层过渡、letterbox 进入；
  - `device`：2.5D 载体/装置、充能/装填；
  - `fire`：发射/飞行；
  - `impact`：命中/冲击环/延迟音爆；
  - `aftermath`：余波/绕坑/回位。
- **跳过**：一个键（默认 `K` 或与参考包一致的可配置键）；跳过时直接跳到 `aftermath` 段，
  把电影的屏幕遮罩淡出，服务端结算照常。
- **过场开关**：客户端配置 `orbital_strike.cutscenes`；关闭时只保留地面/HUD 特效。
- **对附近玩家播放**：服务端把电影包发给半径内玩家；每个客户端可单独跳过/关闭。
- **速度倍率**：`film_speed` 同时缩放电影和服务端相位；参考包 0.3–3×。

### 3.3 屏幕语言（不用 shader）

- Letterbox 上下黑边（现有 `renderCinematicBars` 扩展）。
- 相位字幕/代号（`SS-03 · GUNGNIR // NEEDLE RELEASED`）。
- 冲击帧：白闪/反色/墨线/半调——用 2–3 层全屏叠色 + 短暂停顿实现，不做 36 种 shader 模式。
- 色差/暗角/径向模糊：用屏幕边缘的彩色渐变/半透明环近似；不做 FBO。
- 真实方块粒子：命中时从服务端/客户端采样被毁方块，发 `BlockParticleOption`（参考包做法）。

## 4. 数据化：XML/JSON

参考包把时间轴写死在 Java 里；我们已经有 `pause_menu.xml` 的成功经验，可以把**技能定义**
也做成数据：

`assets/apocalypse_zombies/strike/<id>.xml`：

```xml
<strike id="gungnir" codename="SS-03 · GUNGNIR" color="#FF5A1F"
        cooldown="480" default-power="4">
  <film duration="360" speed="1.0">
    <phase name="mark"      start="0"   end="24"/>
    <phase name="ascent"    start="24"  end="64"/>
    <phase name="device"    start="64"  end="220"/>
    <phase name="fire"      start="220" end="240"/>
    <phase name="impact"    start="240" end="280"/>
    <phase name="aftermath" start="280" end="360"/>
  </film>
  <terrain shape="shock" radius="400" depth="surface" needle="true"/>
  <sounds>
    <cue tick="0"   event="orbital_arm"/>
    <cue tick="9"   event="orbital_mark"/>
    <cue tick="220" event="orbital_hush"/>
    <cue tick="240" event="orbital_crack"/>
    <cue tick="240" event="orbital_boom" delay="distance/340*20"/>
  </sounds>
</strike>
```

- 解析器可复用 `PauseMenuLayout` 的 JDK `DocumentBuilder` 方式；资源包可覆盖调参。
- **相机关键帧** P0 先留在 Java（数学多、XML 表达力有限）；XML 负责相位/音效/颜色/地形参数。
- 失败回落：XML 缺失/解析失败 → 内置默认定义，绝不让技能失效。

## 5. 服务端地形签名与性能

现有 `LayerJob/ColumnJob/BoxJob` 扩展为按技能分发的 `StrikeJob`：

| Job | 技能 | 形状 | 预算/风险 |
|---|---|---|---|
| `ColumnJob` | SS-01 | 整列到虚空 | 现成；4000 格/tick |
| `LineJob` | SS-02 | 大圆线沟槽 | 线长×线宽×深；预算式推进 |
| `ShockJob` | SS-03 | 平面冲击到落点高度 | 400 半径≈50 万格；必须分环/分块，**高风险** |
| `NeedleJob` | SS-03 | 中心针体 | 小；额外方块/掉落 |
| `ConstellationJob` | SS-04 | 7 坑 + 6 沟槽 | 中；每坑独立预算，可交错 |
| `LiftJob` | SS-05 | 64 格抬升/阶梯坑 | 高；完整抬升放 P2，P0 用阶梯+碎块 |
| `OrreryJob` | SS-06 | 主坑 + 环状副坑 | 中；主坑复用 BoxJob，副坑小 |

- 统一 `BLOCKS_PER_TICK` 预算、chunk ticket、掉落方块上限、光照更新节流；
- 破坏前先采集**方块样本**给客户端做 `BlockParticleOption`；
- 保护：基岩/领地/保护插件（若检测到则跳过）；创造模式 evac；生存站区内死亡；
- 余波：余烬/针体/星核/线框/玻璃线，按技能保留 30s–永久。

**性能红线**：400 半径的平面冲击和 64 格抬升不能一次性做；必须渐进取样、分环/分波，
并在配置里给“危险尺寸”警告（参考包也这么做）。

## 6. UX：Stellar Remote 菜单

参考包的遥控器 UX 值得直接学：

- **技能菜单**（径向/轮盘或列表）：六个技能图标、名称、冷却、已选键位、锁定状态；
- **冷却**：图标环形进度 + `Ready / 12s`；
- **滑条**：功率/尺寸（同一概念）、伤害、速度 0.3–3×；
- **过场**：开/关、对附近所有人播放、跳过提示；
- **危险警告**：尺寸超过阈值时提示可能卡顿；
- **按键绑定**：每个技能可绑一个键，冲突时提示“同时触发”；
- **HUD**：目标角框、`SS-0X · CODENAME`、相位状态、距离、倒计时、`[K] SKIP`。

我们现有的 `AmmoWheel`（枪械弹种轮盘）可以复用为技能轮盘的交互骨架；
`DoomButton`/`DoomMenuTheme` 可以复用为菜单外观；`PauseMenuLayout` 的 XML 思路可以复用为
技能菜单布局。

## 7. 实施路线

### P0（先做一刀，验证“电影 + 地形签名”）

推荐 **SS-04 七星（STORM）**：

- 我们已有 5 点风暴的骨架；升级为 7 节点北斗 + 6 条连线沟槽 + 星核；
- 不需要新的大贴图（星座/沟槽/星核用程序化 + 简单方块）；
- 能一次性验证：电影相位、镜头、音效 cue、地形 Job、余波、跳过/开关；
- 工作量中等、风险低，视觉回报高。

P0 同时做**电影框架**（相位/镜头段/跳过/letterbox/字幕）和 **XML 技能定义**的骨架。

### P1

- **SS-03 冈格尼尔**：平面冲击 + 针体 + 静默/延迟音爆（声音设计的巅峰）；

### P2

- **SS-05 超立方**：完整 64 格抬升/四波/线框（性能工程）；

- Stellar Remote 菜单、滑条、冷却 UI、过场广播、速度倍率、危险警告；
- 音效库扩充（原创/授权素材）、方块粒子、性能调优。

## 8. 约束、风险与合规

- **渲染**：继续只用原版 `RenderType`（`entityTranslucentEmissive` / `lines` / `debugQuads`）+
  NEW_ENTITY 全属性顶点；不建自定义 RenderType、不做 shader/FBO（Embeddium 兼容）。
- **相机**：继续用 `ComputeCameraAngles` + 反射；不引入 Mixin。
- **性能**：平冲击/抬升必须分帧/分环；提供危险尺寸警告；服务端主线程预算；
- **多人**：电影广播要可跳过/可关；不能冻结非施法玩家的操作；权限/领地保护；
- **资产**：参考包的贴图/音效/字体/代码不复制；本设计只取结构。新音效优先用原版层 +
  我们已有的 OGG + 原创/授权素材；新方块贴图自己画。
- **存档**：新增方块/数据要可回退；技能定义版本号；旧存档缺少定义时用默认。

## 9. 建议的第一刀

> **P0 = 统一电影框架 + SS-04 七星。**
>
> 理由：我们已经有 STORM 的 5 点骨架、2.5D 电影板、粒子/地形 Job；把 5 点升级成 7 节点 +
> 连线沟槽 + 星核，是“内容升级”而不是“重写引擎”。做完这一刀，玩家能立刻感受到
> “它不再是一个粒子技能，而是一部电影 + 一个地形签名”；之后再接冈格尼尔的静默/音爆、
> 轨道炮的骑弹头、子午线的线切割，风险就可控了。

如果先做冈格尼尔，收益更大但内容更重（平面冲击 400 半径 + 新方块 + 针体 + 延迟音爆）；
如果先做轨道炮，现有代码复用最多但新鲜感最低。三者都可行，建议按“七星 → 冈格尼尔 →
轨道炮/子午线 → 超立方/天球仪”的顺序推进。
