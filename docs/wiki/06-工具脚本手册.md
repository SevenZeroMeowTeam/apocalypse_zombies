# 06 · 工具脚本手册（`tools/`，105 个文件）

**先看这条**：每个脚本头部都有中文 docstring，写清了"为什么需要它"和高频用法。**不认识的脚本，先 `head -20` 它**，
比翻本页快。命名前缀本身就是分类：

| 前缀/后缀 | 含义 |
|---|---|
| `check_*.py` | **门禁**：判据是退出码，输出里出现 `FAIL/✗` 即不通过 |
| `_deploy_*.py` | **出货脚本**，一版一个 |
| `_scratch_*` / `_search_sweep.py` | **一次性草稿**，随时可删；不要依赖 |
| `<武器>_bb_gen.js` / `<武器>_v2.py` | 该武器的**几何+贴图生成器（真源）** |
| `<武器>_anim*.py` | 该武器的**动画关键帧数据（真源）** |
| `bride_*` | 美女僵尸专项探针/审计（每个都解决过一个具体问题） |
| `*_probe.py` / `*_audit.py` / `*_check.py` | 一次性探针与审计，不是门禁 |

## RSC M1917 外形重建三件套（1.1.86 新增）

| 脚本 | 作用 | 跑法 / 判据 |
|---|---|---|
| `tools/rsc_1917_measure.py` | 从参考照片**逐列量取**轮廓：alpha>128 定剪影、HSV 分木/金，输出 `art/rsc_1917/profile2.json`（`{mm_per_px, y_axis_px, total_mm, cols[{z_mm,top,bot,runs}]}`，mm 相对膛线轴） | `py -3.13 tools/rsc_1917_measure.py [--show]`；需 numpy（Windows 上用 `py -3.13`，`py` 会按 shebang 选到无 numpy 的 graalpy） |
| `tools/rsc_1917_silhouette.py` | 模型剪影 vs 真值表逐列对误差 | `py -3.13 tools/rsc_1917_silhouette.py --geo build/rsc_1917_gen.geo.json`；判据 IoU ≥ 0.90、上缘 RMS ≤ 3.0 mm、下缘 RMS ≤ 5.0 mm、**单列最大偏差 ≤ 10 mm**（`--edge-tol`，默认 10 —— RMS 会把点状尖摊平，单列判据才抓得住）；`--ascii` 出双剪影对照、`--skip-bones hand_l` 排除手/弹药件 |
