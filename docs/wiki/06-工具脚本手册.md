# 06 · 工具脚本手册（`tools/`，105 个文件）

**先看这条**：每个脚本头部都有中文 docstring，写清了"为什么需要它"和高频用法。**不认识的脚本，先 `head -20` 它**，
比翻本页快。命名前缀本身就是分类：

| 前缀/后缀 | 含义 |
|---|---|
| `check_*.py` | **门禁**：判据是退出码，输出里出现 `FAIL/✗` 即不通过 |
| `_deploy_*.py` | **出货脚本**，一版一个 |
| `_scratch_*` / `_search_sweep.py` | **一次性草稿**，随时可删；不要依赖 |
| `<武器>_bb_gen.js` / `<武器>_v2.py` | 该武器的**几何+贴图生成器（真源）** |
| `<武器>_anim*.py` | 该武器的**动画关键帧数据（真源）** |
| `bride_*` | 美女僵尸专项探针/审计（每个都解决过一个具体问题） |
| `*_probe.py` / `*_audit.py` / `*_check.py` | 一次性探针与审计，不是门禁 |

## 1. MCP 与 Blockbench 桥

| 脚本 | 用途 |
|---|---|
| `bbmcp_call.py` | 极简 MCP 客户端，直接调 Blockbench MCP 里没进连接器目录的工具。`initialize` 拿 **响应头**里的 `mcp-session-id`，之后每次带这个头（裸 `tools/call` 会被拒） |
| `bb_shot.py` | 从 Blockbench 视图抓图：`python tools/bb_shot.py <view> <out.png> [--cam=x,y,z --target=x,y,z]` |
| `blmcp_call.py` | 同上的 Blender MCP 版（本项目禁用 Blender，仅历史遗留） |
| `awm_bb_load.js` / `awm_bb_pose.js` | 往 Blockbench 里装/摆位 AWM 的脚本 |
