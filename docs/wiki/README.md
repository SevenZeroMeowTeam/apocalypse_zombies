## 五分钟上手

```bash
# 0) 前置：JDK 17（Gradle 找不到工具链时会按 settings.gradle 的 foojay 解析器自己下一个）
# 1) 出三件产物
./gradlew clean build cleanJar borrowedPack

# 2) 部署到本地游戏实例（自升版号 → 构建 → 三向对账 → 探锁部署）
python tools/_deploy_140.py            # 当前最新；每版一个脚本，见「07 出货与版本管理」

# 3) 改过模型/贴图/动画/资源接线 → 门禁必须全绿（13 个脚本，判据是退出码）
for s in tools/check_*.py; do python "$s" || echo "FAIL $s"; done
```

**三条最容易被忽略的前提**

1. **Forge 没有热重载** —— 换包必须等客户端**完全退出**再重开。运行中替换 `mods/` 里的 jar 无效。
2. **本项目禁用 Blender**，预览走自写的软件渲染器（`tools/model_preview.py`），Blockbench 只用来**看和微调**。
3. **几何与动画是绑死的**：重跑几何会重掷骨骼 UUID，动画必须跟着重建；`ADS_X/ADS_Y` 之类的姿态常量必须**量出来**，不许眼估。
