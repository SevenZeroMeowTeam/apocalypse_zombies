# 03 · 构建、运行与排障

## 三件产物

```bash
./gradlew build                                  # 只出开发包
./gradlew clean build cleanJar borrowedPack      # 三件一起出
```

| 产物（都在 `build/libs/`） | 含 TaCZ 借用内容 | 用途 |
|---|---|---|
| `apocalypse_zombies-<ver>.jar` | **有**（22 音效 + 转录动画） | 开发 / 自用。**不得商用、不得公开分发** |
| `apocalypse_zombies-<ver>-clean.jar` | 无 | **分发用**。动画退回完全原创的手工版 |
| `apocalypse_zombies-borrowed-assets.zip` | 有 | 本地资源包，丢进 `resourcepacks/` 把借来的音效/动画覆盖回来 |

后两个由 `build.gradle` 里的自定义任务产出：

- `cleanMeta`（剥元数据）→ `cleanJar`（`Zip`，`dependsOn reobfJar, cleanMeta`）：把 TaCZ 派生内容剔掉，
  并把 `art/awm/awm.animation.handmade.bak.json` **改名为正式动画名**装进去。
  ⚠ 因此在 clean 包里按 `handmade` 找条目会**找不到**（那是假警报），要认**内容哈希**。
- `borrowedPack`（`Zip`）：把那部分内容打成本地资源包。

## 部署到本地实例

```bash
cp build/libs/apocalypse_zombies-1.1.78.jar \
   "F:/.minecraft/versions/1.20.1-Forge_47.4.26/mods/"
```

**但出货一律走脚本**：`python tools/_deploy_<ver>.py`（见 [07 出货与版本管理](07-出货与版本管理.md)）。
它做的是：自升版号 → 构建 → `mods.toml` 与资产**三向对账** → 探锁部署 → 把 `mods/` 里其余模组 md5 逐个断"原样在位"。

**Forge 没有热重载**：必须等客户端**完全退出**再重开。运行中换 jar 无效（进程持有的还是旧包）。
换版本号后**删掉旧 jar**；备份改名成非 `.jar` 后缀。

## 构建卡死的经典故障（本机实测过）

**症状**：日志停在 `The daemon has started executing the build.` 之后不再增长，`build/` 几分钟没有新文件。

**根因**：ForgeGradle 在插件 apply 阶段做**联网探测**时被 socket 阻塞 —— `--offline` / `--no-daemon`
**都管不到它**（它们只作用于 Gradle 自己的依赖解析层）。

**处置**：用一个必定被拒的代理让探测立刻失败（实测：挂 10 分钟零进展 → **25 秒 BUILD SUCCESSFUL**）：

```bash
JAVA_TOOL_OPTIONS="-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=1 -Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=1" \
  ./gradlew build --offline --console=plain
```

`JAVA_TOOL_OPTIONS` 会被**所有** JVM（含 forked daemon）继承；命令行 `-Dorg.gradle.jvmargs="..."` **无效**。

## 常用命令与注意事项

| 需求 | 命令 / 做法 |
|---|---|
| 快、不联网 | `./gradlew build --offline`（依赖已在缓存里时） |
| 清僵尸 daemon | `./gradlew --stop`（构建行为诡异时先做） |
| 跑客户端调试 | `./gradlew runClient`（`build.gradle` 的 `runs.client`，工作目录 `run/`） |
| 只编 Java | `./gradlew compileJava` |
| 看是否用了 JDK 17 | 构建开头会打印 `Java: 17.x, JVM: ...` |
| 长构建 | 别用前台超时硬等，放后台并 `tee` 日志（CI 就是这么做的） |

> `org.gradle.jvmargs=-Xmx4G`、并行与缓存都在仓库 `gradle.properties` 里开好了。

## 错误 → 处置对照

| 症状 | 疑似原因 | 处置 |
|---|---|---|
| 配置期崩：`Illegal character in opaque part ... D:\java` | 仓库里写了 Windows 绝对路径的 JDK 位置 | 挪到用户级 `~/.gradle/gradle.properties` |
| `No matching toolchains found for ... 17` | 本机/runner 上没有 JDK 17，且解析器被禁用 | 确认 `settings.gradle` 有 foojay 解析器、`auto-download=true`、用户级没写 `auto-download=false` |
| 构建卡在配置阶段不增长 | ForgeGradle 联网探测被阻塞 | 上面那条 `JAVA_TOOL_OPTIONS` 假代理 |
| 游戏启动即崩 | `mods/` 里有同 modid 的两份 jar | 删掉旧版本号那份 |
| 枪在游戏里**不显示**，无报错 | Java 里声明的资源路径与磁盘不符 | `python tools/check_gun_resources.py` |
| 换弹/开火动作**静默不播** | 动画 clip 名与 Java 取的键名不一致（如导出的 `animation.<name>` 前缀） | 见 [04 美术规范速查](04-美术规范速查.md) 与 `art/<功能>/DELIVERY.md` 的"踩坑" |
| 改完几何后动画错乱/骨骼乱飞 | 几何重跑重掷了骨骼 UUID | 按顺序重建动画（几何 → geo → 动画），并先删同名 clip |
