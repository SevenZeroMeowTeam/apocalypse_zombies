# 01 · 环境与工具链

## 运行环境要求

| 项 | 值 | 出处 |
|---|---|---|
| Minecraft | `1.20.1` | `gradle.properties` 的 `minecraft_version` |
| Forge | `47.4.0+`（开发机运行实例 `47.4.26`） | `forge_version` / 实例目录名 |
| GeckoLib | `4.8.4` —— **硬依赖**（`mandatory=true`），**不随模组分发**，玩家自行安装 | `geckolib_version`、`NOTICE.md` |
| JDK | **17**（`build.gradle` 的 `java.toolchain.languageVersion = 17`） | 构建脚本 |
| Gradle | **8.8**，由 wrapper 固定：`gradle/wrapper/gradle-wrapper.properties` | wrapper |
| Python | 3.10+，工具脚本**刻意只用标准库**（无 PIL / numpy 依赖） | `tools/*.py` 头部说明 |
| 许可 | 代码 `GPL-3.0-or-later`；含 TaCZ 借用内容的开发包另受 `CC BY-NC-ND 4.0` 约束 | `NOTICE.md` |

**JDK 不需要手工准备**：`settings.gradle` 挂了 `org.gradle.toolchains.foojay-resolver-convention`，`gradle.properties` 开了
`org.gradle.java.installations.auto-download=true`，找不到 JDK 17 时 Gradle 会自己下到 `~/.gradle/jdks/`。

> ⚠ **机器专属配置不许进仓库**。本机的额外 JDK 位置写在**用户级** `~/.gradle/gradle.properties`
> （`org.gradle.java.installations.paths`、`org.gradle.java.home`）。写进仓库版本会被 CI 带到 Linux 上，
> 而 `D:\java` 这种 Windows 绝对路径会被 Gradle 当 **URI** 解析，配置期直接崩：
> `java.net.URISyntaxException: Illegal character in opaque part at index 2: D:\java`。

## 工具链分工

| 环节 | 工具 | 说明 |
|---|---|---|
| 几何与贴图 | **自写生成器**（`tools/<武器>_bb_gen.js`、`<武器>_v<N>.py`）+ `boxlib` 图元 | 程序化生成是**主路径**，Blockbench 不是 |
| 看模型 | `tools/model_preview.py`（正交软渲染）、`tools/atlas_preview.py`（图集） | **Blender 在本项目被禁用** |
| Blockbench 交互 | MCP 插件服务 `http://localhost:3000/bb-mcp`，桥接脚本 `tools/bbmcp_call.py` | 只在需要看/微调时用；抓图 `tools/bb_shot.py` |
| 动画 | `tools/<武器>_anim*.py`、`tools/tacz_anim_transcribe.py` | 关键帧数据写在 Python 里，导出成 `.animation.json` |
| 门禁 | `tools/check_*.py`（13 个） | 判据是**退出码**；输出里出现 `FAIL/✗` 即不通过 |
| 量算 | `tools/pose_measure.py` 等探针 | 姿态常量（`HIP_*`、`ADS_X/ADS_Y`）必须量出来 |
| 出货 | `tools/_deploy_<ver>.py`（124 → 140，共 16 个） | 自升版号 + 构建 + 对账 + 探锁部署 |
| 游戏取证 | `tools/game_shot.py`（窗口截屏）、`tools/game_frames.py` | 纯 ctypes，无 PIL |

## 游戏实例（部署目标）

| 项 | 值 |
|---|---|
| 启动器 | PCLCE |
| 实例 | `F:/.minecraft/versions/1.20.1-Forge_47.4.26/` |
| `mods/` | 同上路径下的 `mods/`（`%APPDATA%\.minecraft` 是空壳，**别往那儿放**） |

**两条保命规则**（`readme.md` 同款）：

- 换版本号后**必须删掉 `mods/` 里的旧 jar** —— 同名模组存在两份会让游戏启动即崩。
- 备份一律**改成非 `.jar` 后缀**（如 `.jar.old.bak`）：Forge 只扫 `.jar`，留着旧文件不会被加载。

## 本机特有的坑（换机器可忽略）

- **hosts**：本机 hosts 里有 Hermes 托管块把 `github.com` / `raw.githubusercontent.com` / `api.github.com` 指到固定 IP。
  GitHub 推送或拉取异常时先查它（备份文件 `hosts.bak.hermes`）。
- 认证走 **SSH**（`git@github.com:SevenZeroMeowTeam/apocalypse_zombies.git`）；本机 `gh` CLI **未登录**，
  要调 GitHub REST/GraphQL 请走已配置的 MCP 连接器或浏览器会话。
