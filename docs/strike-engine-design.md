# 《天陨》打击引擎 v2 与原创末日协议设计

> 方向：**引擎重写，内容原创。**
> The Shooting Star 只作为“电影结构 / 地形签名 / 声音节奏 / 数据化 UX”的参考，
> 不复制它的代码、贴图、音效、字体或六个技能内容。参考包拆解见
> `docs/the-shooting-star-teardown.md`。

---

## 0. 我们到底要做什么

现有打击系统的问题不是“特效不够多”，而是**六种弹种除了伤害和光柱颜色，几乎没有区别**：

- 六种模式共用同一套锁定/下落/落地；
- 地形结果主要是“立方坑 / 整列 / 分层”，没有各自的地貌记忆点；
- 电影只有一套拉远和回位；
- 没有“这一击打完，世界留下什么”的余波；
- 没有可跳过的过场、没有技能菜单、没有速度/尺寸/伤害的统一调参。

v2 的目标：

1. **重写打击引擎**：相位状态机 + 协议定义 + 电影导演 + 地形计划，服务端权威、客户端演出；
2. **六种原创“末日协议”**：每一种有自己的幻想、前摇、电影、地貌、声音、余波；
3. **数据化**：协议用 XML/JSON 定义（相位、音效、颜色、地形参数），资源包可覆盖；
4. **可玩性**：冷却、尺寸/伤害/速度、过场开关、跳过、对附近玩家播放；
5. **不照抄**：只借结构，不借内容；不引入 shader/FBO/Mixin。

一句话：**从“六种光柱”变成“六份末日预案”。**

## 1. 引擎 v2 架构

### 1.1 分层

```
server/
  StrikeProtocolRegistry     ← 读取 strike/*.xml，六份协议定义
  StrikeInstance             ← 一次打击的相位状态机（MARK→…→AFTERMATH）
  StrikePhase                ← 相位事件（开始/结束 tick、半径、参数）
  TerrainPlan / *Job         ← 地形计划：Column/Rift/Cordon/Brood/Purge/Rain
  StrikePacket               ← 协议 id、相位、目标、半径、时间参数
client/
  StrikeClientState          ← 当前协议/相位/进度（服务端包驱动）
  StrikeFilmDirector         ← 镜头段、缓动、FOV/roll、letterbox、字幕、skip
  StrikeVisual               ← 按协议渲染：2.5D 电影板 / 程序化几何 / 粒子
  StrikeHud                  ← 代号、相位、倒计时、[K] SKIP、警告
shared/
  StrikeProtocol             ← id/名称/代号/颜色/相位表/地形参数/音效 cue
  StrikeParams               ← 半径、伤害、速度、深度、是否留痕……
```

### 1.2 相位模型

所有协议共用六个相位，但**每个协议的时长和内容不同**：

| 相位 | 作用 | 默认长度（可配） |
|---|---|---|
| `MARK` | 地面标记、HUD、倒计时、撤离判定 | 20–120t |
| `ASCENT` | 镜头离地、天空过渡、letterbox 进入 | 30–50t |
| `DEVICE` | 载体/装置特写、充能/装填/对齐 | 80–160t |
| `FIRE` | 发射、弹体飞行、光束扫过 | 10–60t |
| `IMPACT` | 命中、冲击环、延迟音爆、破坏开始 | 20–60t |
| `AFTERMATH` | 余波、绕坑/回位、留痕/刷怪/降雨 | 60–200t |

- 服务端 `StrikeInstance` 只负责**权威相位**和地形/伤害；客户端电影按同一份协议时间表播放。
- 速度倍率 `film_speed` 同时缩放相位和电影（0.3×–3×）。
- 相位事件通过 `StrikePacket` 发给客户端；客户端可自行 skip（只跳过电影，不跳过结算）。

### 1.3 电影导演

- `ShotFrame(Vec3 position, Vec3 look, float fov, float roll)`；
- `ShotSegment(start, end, blendIn, path)`；段间 smoothstep/cubic 过渡；
- 锚点：玩家眼位、目标点、天空装置点、弹体位置（骑弹头）、弹坑边缘；
- **镜头语言库**（原创）：
  - `ground-ritual` 手部/遥控器特写；
  - `rise` 绕玩家仰拍 → 升空；
  - `device-hero` 装置三视角（远景/侧推/炮口）；
  - `chase` 骑弹头/光束俯冲；
  - `impact-close` 贴脸命中；
  - `crater-orbit` 绕地貌一圈；
  - `return` 拉远回眼位。
- 每个协议从库里选 4–7 段，组成自己的电影；不再共用一条时间线。
- 过场开关/跳过：客户端配置 + `K`；skip 直接跳到 `AFTERMATH` 的相机段。
- 对附近玩家播放：服务端把包发给半径内玩家；每个客户端可单独 skip/关闭。

### 1.4 地形计划

| Plan | 形状 | 用途 |
|---|---|---|
| `ColumnPlan` | 圆柱整列 | 焚城/黎明等贯穿型 |
| `RiftPlan` | 折线裂谷 | 断层 |
| `CordonPlan` | 环带/围墙 | 隔离 |
| `BroodPlan` | 7 个巢穴坑 | 蜂群 |
| `PurgePlan` | 浅盘 + 玻璃环 | 黎明 |
| `RainPlan` | 云团/污染池 | 黑雨 |

- 统一 `BLOCKS_PER_TICK` 预算、chunk ticket、掉落物上限、光照节流；
- 破坏前采样方块状态，给客户端发 `BlockParticleOption`；
- 保护：基岩/领地/保护插件；创造模式 evac；生存区内死亡；
- 留痕：余烬、裂谷辉光、玻璃环、巢穴、光柱、污染池（30s–永久，按协议）。

### 1.5 数据化

`assets/apocalypse_zombies/strike/<protocol>.xml`：

```xml
<protocol id="fault" mode="lance" codename="FAULT // 断层" color="#D9B26A">
  <phases>
    <phase name="mark" start="0" end="40"/>
    <phase name="ascent" start="40" end="80"/>
    <phase name="device" start="80" end="180"/>
    <phase name="fire" start="180" end="200"/>
    <phase name="impact" start="200" end="240"/>
    <phase name="aftermath" start="240" end="320"/>
  </phases>
  <terrain shape="rift" length="96" width="6" depth="32" glow="true"/>
  <sounds>
    <cue tick="0" event="orbital_arm"/>
    <cue tick="40" event="orbital_ascent"/>
    <cue tick="180" event="orbital_fire"/>
    <cue tick="200" event="orbital_crack"/>
    <cue tick="200" event="orbital_rumble" delay="distance/340*20"/>
  </sounds>
</protocol>
```

- 解析器复用 `PauseMenuLayout` 的 JDK `DocumentBuilder` 方式；失败回落内置定义。
- 镜头关键帧 P0 先留在 Java（数学多）；XML 负责相位/音效/颜色/地形/文案。
- 协议定义带版本号，旧存档缺定义时使用默认。

### 1.6 迁移策略

- v2 **与旧引擎并存**：配置 `orbital_strike.engine_v2`（默认逐步开启）；
- 先迁移一个协议（P0），其余仍走旧 `OrbitalStrikeManager`；
- 每迁移一个协议，保留旧路径作为 fallback；
- 全部迁移后删除旧硬编码时间线，`OrbitalCinematic` 只保留相机反射与通用工具。

## 2. 六种原创末日协议

> 现有六种弹种/载体保留，但内容全部重写为“末日预案”。名字、地貌、声音都不是参考包的技能。

### 2.1 焚城 · CINDER（轨道炮 / CANNON）

- **幻想**：一根钨棒从废弃轨道平台落下，砸穿地壳，点燃整片弹坑；灰烬雨下 40 秒。
- **前摇**：红色目标矛 + 燃烧准星；防空警报；`CINDER // 焚城` 倒计时。
- **电影**：手部 → 升空 → 平台/炮管 → 钨棒装填/加速 → **骑棒俯冲** → 命中 → 火风暴环 →
  绕燃烧的坑 → 回位。
- **地貌**：整列贯穿（现有 ColumnJob）+ 坑沿焦黑 + 坑内火焰/岩浆斑 + 灰烬雨。
- **声音**：警报/装填/释放/风/撞击/火风暴/余烬。
- **留痕**：燃烧弹坑 + 灰烬粒子 40s；坑沿玻璃化。
- **角色**：纯破坏/区域封锁。

### 2.2 断层 · FAULT（天基长矛 / LANCE）

- **幻想**：一根地震钉被射进地层，沿目标朝向撕开一条**折线裂谷**，把地表和尸群一起吞下去。
- **前摇**：一条抖动的**裂缝预告线**沿目标朝向延伸；地面震动；`FAULT // 断层`。
- **电影**：手部 → 升空 → 质量投射器 → 钉体装填/电磁加速 → 钉体斜插入地 →
  **地面沿折线炸开** → 裂谷两侧塌陷 → 绕裂谷 → 回位。
- **地貌**：折线裂谷（长 48–192、宽 4–12、深 16–64），谷底发光；两侧阶梯塌方；
  谷口有钉体残骸（可挖）。
- **声音**：低频震动/装填/钉入/岩层撕裂/塌方/谷底嗡鸣；**主裂开声按距离延迟**。
- **留痕**：发光裂谷 + 塌方阶梯 + 钉体残骸。
- **角色**：线性地形改造/分割战场；与圆形弹坑形成鲜明对比。

### 2.3 隔离 · QUARANTINE（引力奇点 / GRAVITY）

- **幻想**：环状空间站投下一圈**隔离力场**，把区域内的感染者全部“消毒”，留下一圈玻璃围墙和中心信标。
- **前摇**：地面出现白色圆环（半径可调）；环内出现六边形网格；`QUARANTINE // 隔离`；
  环内玩家收到“即将隔离”提示（创造模式 evac）。
- **电影**：手部 → 升空 → 环站展开 → 力场环锁定 → **环壁从外向内收束** → 白闪 →
  环内一切静止/净化 → 玻璃环/信标 → 回位。
- **地貌**：**不炸坑**；边界一圈玻璃化/白化方块（可配置），环内浅层净化（草/木/菌类枯萎），
  中心留下**隔离信标**（发光柱，持续 60s）。
- **声音**：力场嗡鸣/环锁定/收束/白闪/玻璃结晶/信标。
- **留痕**：玻璃环 + 中心光柱；环内怪物被清除（亡灵即死；玩家安全）。
- **角色**：防御/净化/建立安全区；不是破坏技。

### 2.4 蜂群 · SWARM（等离子风暴 / STORM）

- **幻想**：等离子舰投下 7 枚** brood pod（巢荚）**，在目标周围排成蜂巢；每枚孵化出一小窝感染者，
  区域变成巢穴。威力大，但会**唤醒尸群**——风险与收益并存。
- **前摇**：7 个六边形节点亮起；空气出现孢子；`SWARM // 蜂群`；警告“会唤醒尸群”。
- **电影**：手部 → 升空 → 等离子舰 → 巢荚分离 → 7 枚依次落下（每 8–12t）→ 巢荚裂开 →
  绿色孢子云 → 回位。
- **地貌**：7 个小坑 + 巢荚方块（可破坏）+ 蜂巢树脂/孢子地面；每个巢荚按配置刷出
  2–6 只僵尸（不刷精英，避免失控）；可被玩家提前打碎。
- **声音**：虫群/孢囊/裂壳/孢子喷发/蜂巢低鸣。
- **留痕**：巢荚/树脂/孢子；未清除会持续小概率刷怪（可配置关闭）。
- **角色**：生物战/区域控制；与“纯破坏”形成反差。

### 2.5 黎明 · DAWN（宇宙激光 / LASER）

- **幻想**：卫星反射镜把一束“黎明”聚焦到地面——白金色的光柱净化一切亡灵，留下玻璃坑与光柱。
- **前摇**：天边出现一条白线，天空变亮；目标处出现白色光斑；`DAWN // 黎明`；亡灵在区内会本能逃离（可配置）。
- **电影**：手部 → 升空 → 卫星/反射镜阵列 → 镜面聚焦 → 一条白金光柱落下 → 白闪 →
  玻璃化 → 光柱残留在坑中心 → 回位。
- **地貌**：浅盘玻璃坑 + 边缘玻璃环 + 中心**黎明光柱**（60s）；亡灵即死，玩家安全（或按配置）。
- **声音**：晨钟/低频 swell/镜面聚焦/白闪/玻璃/光柱余响。
- **留痕**：玻璃坑 + 光柱；白天/夜晚都可见。
- **角色**：反亡灵终极技/净化；不破坏地形深度。

### 2.6 黑雨 · BLACK RAIN（行星陨落 / PLANET）

- **幻想**：一颗**彗星/污染陨石**砸下，释放出黑色毒雨云；雨区持续伤害、熄灭火焰、留下黑色污染池。
- **前摇**：天空出现黑云/彗尾；目标处出现黑色雨圈；`BLACK RAIN // 黑雨`；警告“毒雨”。
- **电影**：手部 → 升空 → 彗星/小行星飞向地球（现有 2.5D 小行星场景）→ 撞击 → 黑色云团爆发 →
  毒雨落下 → 污染池 → 回位。
- **地貌**：主坑（浅、宽）+ 黑色污染池（新方块/贴图）+ 雨云；雨区内持续中毒/凋零、
  火焰熄灭、植物枯萎；雨持续 30–60s。
- **声音**：彗星呼啸/撞击/云爆/雨声/嘶嘶/低鸣。
- **留痕**：黑水池/污染地面/残云。
- **角色**：持续区域伤害/环境改造；与焚城的火、黎明的净化形成三重对比。

## 3. 和参考包的区别（只借结构，不借内容）

| 参考包 | 我们的原创 | 差异 |
|---|---|---|
| SS-01 轨道炮：红色光柱、挖到虚空 | 焚城 CINDER：钨棒 + 火风暴 + 灰烬雨 | 不是“只挖柱”，而是“火 + 灰”的地貌 |
| SS-03 冈格尼尔：木星加速环 + 黑针 + 音爆 | 断层 FAULT：地震钉 + 折线裂谷 | 没有木星/针体，改成线性裂谷 |
| SS-04 七星：北斗 + 星核 | 蜂群 SWARM：7 巢荚 + 孢子/刷怪 | 不是星座，而是生物战 |
| SS-05 超立方：64 格抬升 | 隔离 QUARANTINE：玻璃环 + 信标 | 不抬地块，而是“圈地净化” |
| SS-02 子午线：镜阵切线 | 黎明 DAWN：太阳聚焦 + 光柱 | 不是线切割，而是反亡灵净化 |
| SS-06 天球仪：行星/轨道 | 黑雨 BLACK RAIN：污染彗星 + 毒雨 | 不是多体轨道，而是环境灾难 |

共同保留的只是“六幕电影 + 地貌签名 + 音效 cue + 可跳过”的**生产结构**。

## 4. UX：天陨协议菜单

- 遥控器打开**协议轮盘**（复用 `AmmoWheel` 的交互骨架，外观用 `DoomButton`/末日主题）；
- 六个协议图标、代号、冷却、已绑按键；
- 参数：半径/尺寸、伤害、速度 0.3–3×；
- 过场：开/关、对附近玩家播放、`K` 跳过；
- 危险尺寸警告（大范围冲击/刷怪可能卡顿或失控）；
- HUD：`CINDER // 焚城`、相位、倒计时、`[K] SKIP`、区内警告。

## 5. 实施路线

### P0：引擎核心 + 断层 FAULT

选 FAULT 作为第一刀：

- 它需要一个新的 `RiftPlan`（折线裂谷），是**全新的地貌签名**；
- 不需要新实体/AI（蜂群要刷怪，隔离要力场规则，黑雨要天气）；
- 复用现有长矛 2.5D 电影板和相机；
- 能验证：协议 XML、相位状态机、电影导演、地形计划、延迟音效、skip/HUD。

P0 交付：

- `StrikeProtocol`/`StrikeProtocolRegistry`（XML 解析 + 内置回落）；
- `StrikeInstance` 相位状态机（MARK/ASCENT/DEVICE/FIRE/IMPACT/AFTERMATH）；
- `StrikeFilmDirector`（镜头段/缓动/FOV/roll/skip/letterbox/字幕）；
- `RiftPlan` + `RiftJob`（折线裂谷、塌方、钉体残骸、发光谷底）；
- `fault.xml`；
- 旧五模式仍走 v1，配置可切回。

### P1

- SWARM（巢荚/孢子/刷怪/风险警告）；
- QUARANTINE（玻璃环/信标/亡灵净化）；
- CINDER 的电影/火风暴/灰烬（复用 ColumnJob）。

### P2

- DAWN（光柱/玻璃/反亡灵）；
- BLACK RAIN（毒雨云/污染池/环境伤害）；
- 协议轮盘/参数滑条/过场广播/性能调优。

## 6. 约束与验收

- 渲染：原版 `RenderType`（`entityTranslucentEmissive`/`lines`/`debugQuads`）+ NEW_ENTITY 全属性；
  不建自定义 RenderType、不做 shader/FBO（Embeddium 兼容）。
- 相机：`ComputeCameraAngles` + 反射；不引入 Mixin。
- 服务端：预算式 Job、chunk ticket、保护/权限、创造 evac、生存死亡规则。
- 资产：不复制参考包；新方块贴图/音效原创或使用已授权素材。
- 验收：六种协议的地貌/声音/电影能被玩家一句话区分；skip/开关可用；
  单次打击 TPS 不低于 18（默认尺寸）；无崩溃。

---

## 7. 结论

**引擎重写、内容原创、参考包只当参考。**
第一刀做 **FAULT / 断层**：用一条折线裂谷证明“新引擎 + 新地貌 + 新电影”这条路成立；
随后是蜂群、隔离、焚城、黎明、黑雨。六份协议做完，玩家看到的就不再是六根光柱，
而是六份会改变世界、留下痕迹的末日预案。
